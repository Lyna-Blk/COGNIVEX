# PRODUIT 3 — DOXYNUP 100 mg

## 1. Identification du médicament

- Nom commercial : DOXYNUP
- DCI : DOXYCYCLINE
- Substance active : Doxycycline monohydratée exprimée en doxycycline
- Dosage : 100 mg
- Forme pharmaceutique : Comprimé dispersible
- Conditionnement : Boîte de 6 comprimés
- Classe pharmacologique : Tétracyclines
- Code DCI : 13 C 444
- Laboratoire : HUP.P.PHARMA SARL
- Pays d'origine : Algérie

## 2. Informations réglementaires

- Numéro d'enregistrement (AMM) indiqué : 380/13 C 444/15
- Source consultée : Doctavie
- Lien :
https://doctavie.com/fr/medicaments/doxynup-ae13901b

Remarque : Le numéro d'enregistrement et les informations réglementaires sont rapportés selon la base consultée. Une confirmation directe auprès des documents officiels du MIPH ou de l'ANPP reste recommandée.

## 3. Présentation pharmaceutique

DOXYNUP est présenté sous forme de comprimés dispersibles contenant 100 mg de doxycycline monohydratée, exprimée en doxycycline.

Conditionnement indiqué : boîte de 6 comprimés.

- La forme dispersible doit être distinguée des comprimés sécables.
- Les informations commerciales et réglementaires proviennent de bases secondaires.
- La disponibilité commerciale actuelle doit être confirmée auprès d'un pharmacien.
